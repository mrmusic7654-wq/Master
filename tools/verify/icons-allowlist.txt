# Material icon allowlist for Master Control.
#
# Every `Icons.<Style>.<Name>` used in a production source set must appear here.
# tools/verify/structure-check.py fails the build otherwise.
#
# Two reasons for the rule:
#   1. Accessibility review — an icon is always paired with a word (a StatusChip
#      label, a content description or adjacent text), so each addition is a
#      deliberate decision, never decoration.
#   2. APK size — material-icons-extended is large; a bounded, reviewed set keeps
#      the shipped icon count honest.
#
# Format: one `<Style>.<Name>` per line. `#` starts a comment.
